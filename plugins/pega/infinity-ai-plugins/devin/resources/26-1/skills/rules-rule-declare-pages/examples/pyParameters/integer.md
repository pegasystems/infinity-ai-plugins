---
name: declare-pages-param-integer
description: Integer-typed data page parameter. Used for counts, limits, page sizes, numeric IDs stored as whole numbers. pyParametersParamType must be all-caps "INTEGER", not Title Case "Integer"
---

```json
{
  "pyParametersParamName": "maxEntries",
  "pyParametersParamType": "INTEGER",
  "pyParametersParamInOut": "IN",
  "pyParametersParamReq": "0",
  "pyParametersParamDefaultValue": "100",
  "pyParametersParamDesc": "Maximum entries to return"
}
```
