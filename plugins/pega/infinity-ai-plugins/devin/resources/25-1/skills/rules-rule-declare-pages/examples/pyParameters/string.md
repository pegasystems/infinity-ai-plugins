---
name: declare-pages-param-string
description: String-typed data page parameter. The most common type; used for IDs, names, codes, free-text selectors. pyParametersParamType must be all-caps "STRING", not Title Case "String"
---

```json
{
  "pyParametersParamName": "customerID",
  "pyParametersParamType": "STRING",
  "pyParametersParamInOut": "IN",
  "pyParametersParamReq": "-1",
  "pyParametersParamDesc": "Customer identifier"
}
```
